Help with GlyphDial.

GlyphDial runs locally in the macOS menu bar. These steps solve the most common setup issues without sharing private keyboard or document data.

01

Set permissions

Open GlyphDial Settings and follow the permission prompts. Input Monitoring enables the global trigger. Accessibility enables the temporary filter that reserves only the configured directional keys while the dial is visible.

02

Choose a trigger

Use Fn/Globe + Left Option by default, or choose a physical Option-key mode for an external keyboard that does not expose Fn to macOS.

03

Assign directions

Assign two to four available macOS input sources to fixed Up, Down, Left, and Right slots. Releasing the trigger without a direction leaves the current source unchanged.
