macOS input source switching

A direct route to the right keyboard layout.

GlyphDial is a menu-bar utility for deterministic switching between two to four input sources. Each source keeps a fixed direction, so you select it directly instead of cycling through layouts.

Get supportRead the privacy policy →

01

Fixed directions

Assign every input source to Up, Down, Left, or Right. The choice never depends on the currently active layout.

02

Local by design

Keyboard handling stays on your Mac. GlyphDial has no account, analytics, telemetry, cloud sync, or developer-controlled backend.

03

No typed text

GlyphDial does not inspect, reconstruct, store, or transmit typed characters, clipboard contents, or foreground-app content.
